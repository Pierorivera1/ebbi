# Try Ebbi with sample data

The repository includes a synthetic dataset generator for demos and local checks.
It uses Ebbi's normal storage API and creates a new SQLite database with dates
relative to the local day when it runs:

- Two binary habits and one numeric habit with 90 days of history.
- Numeric successes, misses, missing values, and recorded zeros.
- Three unfinished tasks.
- Four study topics with Markdown notes and twelve reviews, including completed,
  overdue, due today, and upcoming reviews.

From the source checkout, run:

```sh
sample_root="$(mktemp -d)"
cargo run --locked --example sample_data -- "$sample_root/demo"
cargo run --locked -- --db "$sample_root/demo/ebbi.db"
```

The destination directory must not exist; its parent must exist. The generator
refuses existing directories, files, and symlinks instead of overwriting data.
The database and directory are private to your user. It never selects your
normal Ebbi database or reads either legacy app's data.

To switch the running demo to another view, run:

```sh
cargo run --locked -- --db "$sample_root/demo/ebbi.db" --view=study
cargo run --locked -- --db "$sample_root/demo/ebbi.db" --view=analytics
```

Each command routes to the existing demo window and exits. If Ebbi is
installed, use `ebbi --db "$sample_root/demo/ebbi.db"` in place of `cargo run`.
The generator still requires the source checkout and Cargo. The sample is
editable and persists across restarts. Its dates are synthetic; database creation
and completion timestamps record the actual generation time. The existing
[README screenshots](../README.md#screenshots) were captured from an earlier
synthetic dataset and are not regenerated by this example.

To check the generator's persisted records and refusal to overwrite:

```sh
cargo test --locked --example sample_data
```
